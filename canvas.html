如何在電腦上開啟？

點擊下方步驟標記為完成，逐步建立您的學習環境：

📋

1. 複製代碼

複製我提供的 `index.html` 完整程式碼。

📄

2. 建立檔案

在電腦桌面點擊右鍵 -> [新增] -> [文字文件]。

✏️

3. 貼上並更名

將程式碼貼入後儲存，並將該檔案重新命名為 `taigi.html`（確認副檔名是 `.html` 而非 `.txt`）。

🚀

4. 開啟

使用 Chrome 或任何瀏覽器雙擊打開該檔案。

如何在手機上使用？

請選擇最適合您的部署方式：

📤

方法 A：直接傳送

您可以將上述製作好的 `html` 檔案傳送到手機（例如透過 LINE 的「內容傳送」或雲端硬碟），然後用手機內建的瀏覽器直接開啟檔案。

🌐

方法 B：雲端託管

如果您有 GitHub 帳號，強烈建議將此程式碼上傳至 GitHub Pages，即可獲得一個永久的網址，方便隨時隨地開啟練習。
